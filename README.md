# 💼 Personal Portfolio Website

একটি পার্সোনাল পোর্টফোলিও ওয়েবসাইট, যা তৈরি করা হয়েছে **HTML5** ও **CSS3** দিয়ে। এই ওয়েবসাইটে ব্যক্তিগত পরিচিতি, স্কিল, প্রজেক্ট এবং কন্টাক্ট তথ্য প্রদর্শন করা হয়েছে একটি ক্লিন ও রেসপন্সিভ ডিজাইনের মাধ্যমে।

## 🛠️ ব্যবহৃত টেকনোলজি

- **HTML5** — সিমেন্টিক মার্কআপ ও কন্টেন্ট স্ট্রাকচারের জন্য
- **CSS3** — স্টাইলিং, লেআউট (Flexbox/Grid) ও রেসপন্সিভনেসের জন্য

## ✨ মেইন ফিচারসমূহ

- ফুললি রেসপন্সিভ ডিজাইন (মোবাইল, ট্যাব ও ডেস্কটপ ফ্রেন্ডলি)
- About / পরিচিতি সেকশন
- Skills সেকশন
- Projects শোকেস সেকশন
- Contact সেকশন
- ক্লিন, মডার্ন ও মিনিমাল UI

## 📦 ডিপেন্ডেন্সি

এই প্রজেক্টে কোনো JavaScript ফ্রেমওয়ার্ক বা npm প্যাকেজ ব্যবহার করা হয়নি — এটি সম্পূর্ণ **plain HTML ও CSS** দিয়ে তৈরি। তাই আলাদা করে ইনস্টলেশনের প্রয়োজন নেই।

> যদি কোনো external CDN (Google Fonts, Font Awesome ইত্যাদি) ব্যবহার করা হয়ে থাকে, সেগুলোর লিংক এখানে যোগ করুন:
- [Google Fonts](https://fonts.google.com/)
- [Font Awesome](https://fontawesome.com/)

## 🚀 লোকাল মেশিনে রান করার গাইডলাইন

1. প্রজেক্টটি ক্লোন করুন:
   ```bash
   git clone https://github.com/abirhosen30/protofolio-webside.git
   ```
2. প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
   ```bash
   cd protofolio-webside
   ```
3. `index.html` ফাইলটি সরাসরি ব্রাউজারে ওপেন করুন, অথবা VS Code এর **Live Server** এক্সটেনশন ব্যবহার করে রান করুন।
4. Live Server ব্যবহার করলে, `index.html` ফাইলে রাইট-ক্লিক করে **"Open with Live Server"** সিলেক্ট করুন।
